# CurlS
## Released
`CurlS` is now officially **V1.0**.

A small and simple way to download website HTML.

For more information, click [here](HowTo.md)
### Features
* Simple command-line interface
* Windows executable available
### Usage
```bash
curlS --url <url> --out <output dir>
```

Example:

```bash
curlS --url "https://example.com" -out "C:\output"
```
